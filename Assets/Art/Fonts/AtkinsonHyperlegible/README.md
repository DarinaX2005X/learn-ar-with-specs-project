# Atkinson Hyperlegible

Original static OpenType fonts by Braille Institute of America, Regular 400 and Bold 700. Distributed under the SIL Open Font License 1.1 in [OFL.txt](OFL.txt). The files are unmodified.

Source: [Google Fonts Atkinson Hyperlegible repository](https://github.com/googlefonts/atkinson-hyperlegible/tree/1cb311624b2ddf88e9e37873999d165a8cd28b46/fonts/otf), revision `1cb311624b2ddf88e9e37873999d165a8cd28b46`. Exact upstream URLs and SHA-256 hashes are in [sources.json](sources.json).

Import both OTF files as native Lens Font assets. Bind Regular to `CountercaseRuntime.fontRegular` and Bold to `CountercaseRuntime.fontBold`. Both inputs are optional; unbound scenes retain the native default font. No external font request is made at runtime.
