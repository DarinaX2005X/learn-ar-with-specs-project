# TableKit development tools

From the repository root, run:

```sh
python Tools/TableKit/test_tablekit.py
```

Requires Python 3.10+, NumPy, Node.js and npm. If needed, install the validation
dependency with `python -m pip install numpy==1.26.4`.
The runner obtains **TypeScript 5.9.3** through npm's cache, compiles the four
TableKit modules with strict checking into a temporary OS directory, validates
all 15 models and all three WAVs, then runs adapter tests. The temporary output
is removed on exit. No project assets are regenerated by this command.

Asset validation fails when models or audio are missing, unexpected, empty,
malformed, inconsistent with the manifest, or have invalid indices/normals/audio
levels. It includes the affected filename in geometry and audio error messages.

`generate_tablekit.py` regenerates the original GLBs and manifest. Its optional
`--review-dir OUTPUT_DIRECTORY` produces an offline contact sheet only when
requested; it has no dependency on a review directory. That optional render also
requires Pillow. `generate_role_silhouettes.py` requires Shapely and derives the
public head outlines from original head geometry.

To regenerate audio, set `CLAD_SFX_ENGINE` to an installed official CLAD
`build-sfx/tools` directory, then run `node Tools/TableKit/generate_sfx.cjs`.
The engine is an external development dependency; no machine-specific path is
stored in this repository.
